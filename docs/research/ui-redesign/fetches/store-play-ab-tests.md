# Run A/B tests on your store listing - Play Console Help

> Fetched 2026-10-19 · Play Console store listing experiments documentation; read for how to validate redesigned screenshots/icon against conversion. (answer/12053285 returns the identical article text; diffed.)

## What it says

> "To help optimize your store listing on Google Play, you can run experiments to find the most effective graphics and text for your app. You can run experiments for your default and custom Store Listings."

> "For published apps, you can test variants against your current version to see which one performs best based on install/open data."

### Experiment types

> "For each app, you can run one default graphics experiment or up to five localized experiments at the same time."

> "Using a default graphics experiment, you can experiment with graphics in your app's default Store Listing language. You can include variants of your app's icon, feature graphic, and screenshots."

> "If you've added any localized graphic assets in a specific language: Users viewing your app in that language are excluded from your app's default graphics experiments."

> "Using a localized experiment, you can experiment with your app's icon, feature graphic, screenshots, and/or your app's descriptions in up to five languages."

### Create an experiment

> "Target metric: The metric used to determine your experiment's result. Choose Unique user install clicks, Unique user open clicks or Unique user pre-registration clicks."

> "Number of variants: The number of experimental variants to test against the current store listing (you can choose up to 2 variants)."

> "Select the type of asset you want to test. We recommend testing changes to one asset at a time, so you can be as certain as possible of what causes any changes to your store listing performance."

### Review and apply results

> "You may receive the result "More data needed" if not enough data has been collected to return a result."

### Experiment autocompletion

> "Store listing experiments stop automatically after running for 6 months."

## What it does not say

- No traffic threshold; the console "estimates the time and number of acquisition, opens or pre-registrations your experiment will need". A low-traffic app may sit at "More data needed".
- Note for the Portuguese (pt-BR) listing: if the default language is not pt-BR and pt-BR has localized graphics, pt-BR visitors are excluded from a *default graphics* experiment; a *localized* experiment would be needed. The page does not say which to pick.
