# Samsung Galaxy A15 — full specifications (GSMArena)

> Fetched 2026-10-19 · Spec aggregator page for the 4G Galaxy A15 (SM-A155x; the 5G variant uses a different SoC). Read to pin the target device's GPU, RAM and refresh rate.

## What it says

- Chipset: "Mediatek Helio G99 (6 nm)"
- CPU: "Octa-core (2x2.2 GHz Cortex-A76 & 6x2.0 GHz Cortex-A55)"
- GPU: "Mali-G57 MC2"
- Memory: "128GB 4GB RAM, 128GB 6GB RAM, 128GB 8GB RAM, 256GB 6GB RAM, 256GB 8GB RAM"
- Display: "Super AMOLED, 90Hz, 800 nits (HBM)"; "6.5 inches"; "1080 x 2340 pixels, 19.5:9 ratio (~396 ppi density)"
- OS: "Android 14, up to 4 major OS updates, upgradable to Android 16, One UI 8.5"
- Announced: "2023, December 11"

## What it does not say

- Not Samsung's own page (secondary). 1080×2340 px at 384×832 dp implies a density of 2.8125 — derived, not stated.
- Whether One UI runs apps at 90 Hz by default (adaptive "Motion smoothness") — not stated; at 90 Hz the frame budget is ~11 ms (perf-android-slow-rendering.md).
- Haptic motor type (affects how `AndroidHaptics` constants feel).
