# Resolve common onboarding issues - Google AdMob Help

> Fetched 2026-10-19 · Opened because the Android banner guide links "Ad request size requirements" here; hoped to find the anchored banner size limits.

## What it says

### Ad request doesn't meet size requirements

> "The ad request doesn't meet the ad format size requirements for this ad unit."

> "Review the ad format size requirements for your ad units. Verify and update your ad request parameters, then try again."

### Frequency cap reached

> "A frequency cap is set for this ad unit. This means that this ad unit limits the number of ads shown to an individual user."

## What it does not say

- The actual size requirements are not on this page (only a further link). Height bounds were taken from the Unity anchored adaptive guide instead.
