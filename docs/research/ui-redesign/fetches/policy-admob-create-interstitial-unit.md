# Create an interstitial ad unit - Google AdMob Help

> Fetched 2026-10-19 · AdMob console how-to for interstitial units; read because it surfaced in a search for quiz/interstitial guidance.

## What it says

> "Interstitial ad units show full-page ads in your app. Place them at natural breaks & transitions in your app's interface, such as after level completion in a gaming app."

> "Frequency capping: Determines the number of times this ad unit can show an ad to the same user. You can choose not to set a limit, or you can limit ads for each user by the number shown per minute, hour, or day."

## What it does not say

- Nothing quiz-specific; the only placement example is "after level completion in a gaming app".
