# Updated Guidance on Implementing AdMob Interstitial Ads (Google blog, 2015)

> Fetched 2026-10-19 · Google's AdMob blog post (John Brown, Policy Transparency Lead, October 29, 2015) introducing the interstitial rules; read for any statement about showing an interstitial before results. Read through the WebFetch tool (short fragments only).

## What it says

> "Users should not be overwhelmed with interstitial ads."

> "Repeated interstitial ads often lead to poor user experiences and accidental clicks."

> "Placing interstitial ads so that they suddenly appear when a user is focused on a task at hand" … "accidental clicks and often creates a frustrating user experience."

> "users should not be surprised by interstitial ads."

> "ads should not be placed in a way that prevents viewing the app's core content."

## What it does not say

- Nothing about before vs after a break/results page, loading screens, pre-loading, or app load/exit; those are in the current Help Center pages.
