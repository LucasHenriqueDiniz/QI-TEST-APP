# Introducing the WAIS-IV (Pearson presentation, 2008)

> Fetched 2026-10-19 · Publisher slide deck introducing the WAIS-IV. Read for the composite structure, the revision goals about speed, and the Block Design time-bonus change. PDF text extracted with `pdftotext -layout`.

## What it says

Revision goals, "Increase Developmental Appropriateness":
- "Reduce emphasis on motor demands"
- "Reduce emphasis on time-bonus"

Other revision goals: "Enhance Measure of Processing Speed • Develop additional PS subtest: Cancellation"; "Enhance Measure of Fluid Intelligence • Develop additional measure of fluid reasoning: Figure Weights".

Test structure:

| scale | core subtests | supplemental |
|---|---|---|
| Verbal Comprehension | Similarities, Vocabulary, Information | Comprehension |
| Perceptual Reasoning | Block Design, Matrix Reasoning, Visual Puzzles | Picture Completion, Figure Weights (16-69) |
| Working Memory | Digit Span, Arithmetic | Letter-Number Sequencing (16-69) |
| Processing Speed | Symbol Search, Coding | Cancellation (16-69) |

Composite scores slide:
- "FSIQ • Based on 10 core subtests"
- "Index Scores: Primary interpretation level • VCI & PRI: 3 core subtests each • WMI & PSI: 2 core subtests each"
- "GAI = VCI + PRI • Optional Index score"

Block Design changes: "Added 4-block diamond items before 9-block items, Reduced # of items with time bonus, Added BDN process score". Process scores: "Block Design No Time Bonus (BDN)".

Matrix Reasoning: "Retained 2 of 4 item-types, Added sample item for each type, Clarified 30-second guideline".

Normative sample: "N = 2200 – 200 examinees per age band for ages 16-69 – 100 examinees per age band for ages 70-90".

## What it does not say

- The exact Block Design bonus cut-offs or how many items carry a bonus.
- Arithmetic's time limit and whether it awards speed credit (not on these slides).
- Whether the "30-second guideline" on Matrix Reasoning affects scoring (a guideline, not a scored limit, by its wording).
