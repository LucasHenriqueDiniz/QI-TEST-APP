# The International Cognitive Ability Resource (ICAR) — project page (TU Dortmund; icar-project.com redirects here)

> Fetched 2026-10-19 · The project's own page, now hosted by TU Dortmund (https://icar-project.com/ answers 301 to this URL). Read for item types, terms of use and where the items live.

## What it says

- "The International Cognitive Ability Resource (ICAR) project resulted in a large collection of assessment instruments for cognitive abilities that can be used in a wide variety of applications."
- "ICAR makes use of automatic item generation techniques, which produce test items with predictable psychometric properties."
- "Please note that ICAR is intended for academic use exclusively."
- "The ICAR 60 is the most popular test originally developed by Condon and Revelle." It contains Three-Dimensional Rotation, Letter and Number Series, Matrix Reasoning and Verbal Reasoning items.
- "If you are looking for a brief measure, the 12 item "Sample Test" has proven to be surprisingly robust."
- Further item types: Figural Analogies Test, Number Series, Perceptual Maze, Propositional Reasoning; contributed: Face Detection, Figural Analogies (IMak generator), Melodic Discrimination, Children's ICAR.
- "The ICAR can be found at the Leibniz-Institut für Psychologie at https://doi.org/10.23668/psycharchives.22167".

## What it does not say

- Any norms or published item parameters on the page itself.
- Any licence permitting use in a commercial, ad-supported app — the opposite: "academic use exclusively".
