# Table 2. WAIS-IV Subtest Input and Output Requirements and Equivalence Evidence (Pearson telepractice guidance, 2020)

> Fetched 2026-10-19 · Publisher table for remote administration of the WAIS-IV. Read because it is the one public Pearson document that codes, per subtest, whether there is an item-level or task-level time limit. PDF text extracted with `pdftotext -layout`.

## What it says

Output-code legend: "IT = Item-level time limit, MC = Multiple choice, OE = Open ended, PR = Pointing response, … TT = Task-level time limit, WFR = Written or fine motor response."

| subtest | output codes (as printed) | time limit |
|---|---|---|
| Similarities | OE, SPR | none |
| Vocabulary | OE, SPR | none |
| Information | OE, SPR | none |
| Comprehension | OE, SPR | none |
| Block Design | GMR, IT | item-level |
| Visual Puzzles | B or PR, IT, MC | item-level |
| Matrix Reasoning | BSR or PR, MC | none (no IT code) |
| Figure Weights | BSR or PR, IT, MC | item-level |
| Arithmetic | BSR, IT, OE | item-level |
| Digit Span | OE, SPR | none |
| Letter-Number Sequencing | OE, SPR | none |
| Coding | TT, WFR | task-level |
| Symbol Search | TT, SWR | task-level |
| Cancellation | TT, SWR | task-level |
| Picture Completion | BSR, IT, PR | item-level |

Similar-task cross-references the table draws for Coding/Symbol Search: "14–Letter-Pattern Matching (LPM), Sentence Reading Fluency (SRF), Math Facts Fluency (MFF); 15–Speeded Picture Search".

## What it does not say

- The seconds allowed per item, or which items earn time-bonus points (only that a limit exists).
- Matrix Reasoning carries no IT code, consistent with the WAIS-IV deck calling its 30 s a "guideline".
