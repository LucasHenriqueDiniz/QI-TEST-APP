# WAIS-5 overview brochure (Pearson, US)

> Fetched 2026-10-19 · Publisher brochure for the WAIS-5 (2024). Read for the index structure, which subtests feed which index, and the summary indexes (GAI, CPI). PDF text extracted with `pdftotext -layout`; table formatting (bold/italic marks that flag the FSIQ subtests) is lost in the text layer.

## What it says

- "Consisting of a primary battery of 10 subtests that are used to appraise intellect and five cognitive domains — verbal comprehension, visual spatial, fluid reasoning, working memory, and processing speed"
- "Completion time: 45 minutes for the 7-subtest FSIQ; 60 minutes for the 10 primary index subtests"
- "Broader construct coverage of working memory, fluid reasoning, and processing speed … Fluid reasoning: verbal, visual, inductive, quantitative, and logical … Processing speed: verbal and visual"
- "Nonverbal Index, Nonmotor Index, and Motor Reduced Processing Speed Index scores … measures of ability not confounded by expressive language or motor problems"
- Normative sample "collected in 2023-2024".

Test framework (all subtests by domain):

| Verbal Comprehension | Visual Spatial | Fluid Reasoning | Working Memory | Processing Speed |
|---|---|---|---|---|
| Similarities, Vocabulary, Information, Comprehension | Block Design, Visual Puzzles | Matrix Reasoning, Figure Weights, Arithmetic, Set Relations | Digit Sequencing, Running Digits, Digits Forward, Digits Backward, Letter-Number Sequencing, Symbol Span, Spatial Addition | Coding, Symbol Search, Naming Speed Quantity |

Primary index scales (2 subtests each):

| VCI | VSI | FRI | WMI | PSI |
|---|---|---|---|---|
| Similarities, Vocabulary | Block Design, Visual Puzzles | Matrix Reasoning, Figure Weights | Digit Sequencing, Running Digits | Coding, Symbol Search |

Ancillary indexes listed: Expanded indexes (VECI, EVSI, EFI, EWMI, EPSI), domain-specific (Verbal Reasoning, Quantitative Reasoning, Visual WM, Auditory WM-R/M, Motor-Reduced PS), and summary indexes "Nonverbal Index (NVI) · Nonmotor Index (NMI) · General Ability Index (GAI) · Cognitive Proficiency Index (CPI)".

Digital: "administer and score the assessment using two iPad® devices"; "Starter kits, which include paper response booklets for Coding and Symbol Search".
